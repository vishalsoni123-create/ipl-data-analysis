

\# IPL Data Analysis



\## Project Overview

This project analyzes IPL cricket data using Google Sheets.



\## Objectives

\- Inspect and clean the dataset.

\- Analyze team and player performance.

\- Create Pivot Tables and visualizations.

\- Build a dashboard to present key insights.



\## Tools Used
