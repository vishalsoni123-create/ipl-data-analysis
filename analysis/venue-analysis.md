\# IPL Venue-wise Match Analysis



\## About

I analyzed the venue column in my IPL dataset to find out which stadium hosted the most matches.



\## What I Did

\- Created a Pivot Table in Google Sheets.

\- Added venue to Rows.

\- Counted venue records using COUNTA.

\- Created a column chart to compare venues.



\## Top Results



| Venue | Match Count |

|---|---:|

| M Chinnaswamy Stadium | 58 |

| Eden Gardens | 54 |

| Feroz Shah Kotla | 53 |

| Wankhede Stadium | 49 |

| MA Chidambaram Stadium | 48 |



\## My Observation

M Chinnaswamy Stadium has the highest count in my dataset, with 58 match records.



\## Conclusion

The venue analysis shows that match records are distributed differently across stadiums.
