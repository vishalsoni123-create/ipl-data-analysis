

\# IPL Season-wise Match Analysis



\## Objective

Analyze the number of IPL matches recorded in each season.



\## Tool

Google Sheets



\## Method

\- Created a Pivot Table.

\- Rows: season

\- Values: COUNT of season

\- Created a column chart to visualize match counts.



\## Results

\- Total match records: 577

\- Highest match count: 2013 (76)

\- Lowest match count: 2009 (57)



\## Conclusion

The dataset contains different numbers of match records

across seasons from 2008 to 2016.
